진행중 입찰공고

시도 → 시·군 → 면허 → 공고명 순으로 좁혀 보세요. 마감 임박 순으로 보여줍니다.

지역 선택

시·도를 고르면 해당 지역 낙찰 데이터만 불러옵니다. 시·군을 고르면 더 좁힙니다. (복수 선택)

면허 선택

공고의 면허 제한 기준입니다. 비우면 전체. (복수 선택)

예측에 반영할 항목

체크한 항목만 이번 예측에 반영됩니다.

아래 기초금액과 비슷한 규모의 공고만 반영
개찰일이 최근 12개월 이내인 공고만 반영
아래 참가업체 수와 ±2개사 이내인 공고만 반영

투찰가 계산기

투찰금액 = (예정가격 − A값) × 낙찰하한율 + A값. 예측 실행 시 적용 사정율이 자동으로 채워집니다.

발주기관 예가 구간확률

같은 기관의 과거 복수예비가격 15개(기초금액 대비 %)로 4개 조합(1,365가지) 평균을 계산해, 사정율 0.1% 구간별 확률을 보여줍니다.

복수예비가격 시뮬레이터

기초금액 ±예가범위 안에서 예비가격 15개를 무작위로 만들고 4개를 뽑아 예정가격을 정하는 구조를 재현합니다. 참고용이며 실제 추첨 결과를 예측하지 않습니다.

관심공고

입찰공고에서 ☆를 눌러 저장한 공고입니다. 개찰되면 내 예측과 실제 사정율·1위 투찰률을 비교합니다.
